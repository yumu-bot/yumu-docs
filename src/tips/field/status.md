谱面状态字段通常可以按以下方法输入：

| 谱面状态 | 简称 | 数字 |
| :-: | :-: | :-: |
| graveyard | g | -2 |
| wip | w | -1 |
| pending | p | 0 |
| ranked | r | 1 |
| approved | a | 2 |
| qualified | q | 3 |
| loved | l | 4 |
