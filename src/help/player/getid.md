可以通过输入玩家名来获取玩家号。

参见：[玩家/获取玩家名称](./getname.md)

::::: info 使用方法

!getid / gi / 玩家号码 [ ::address-card:: 玩家名+]

:::: tabs

@tab ::address-card:: 玩家名+

必选。参见：[字段/玩家名](../../tips/field/player.md)

可以按分隔符号分隔，输入多个玩家名。参见：[技巧/多值参数](../../tips/trick/multiple.md)

::::

:::::

::: warning 注意

为防止滥用，只有群聊的群主或管理员可以使用此功能。

:::
