可以查询不同模式上的游玩信息。

::::: info 使用方法

!info / i / 玩家信息 (`:` ::gamepad:: 游戏模式) ( ::address-card:: 玩家名) (`#` ::calendar-days:: 天数)

:::: tabs

@tab ::gamepad:: 游戏模式

可选。参见：[成绩/绑定游戏模式 (SM)](../scores/mode.md)

@tab ::address-card:: 玩家名

可选。参见：[字段/玩家名](../../tips/field/player.md)

@tab:active ::calendar-days:: 天数

可选。`#` ==不可省略==。

查询距今数天前的数据，并和现在比较。

- 范围：1-999
- 默认值：1
- 输入单个数字，则返回与距今对应天数的数据比较。

- 使用 !ic 可以获取明信片设计。
