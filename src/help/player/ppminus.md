::: details 数值解析

PPM 4 统计了玩家附近（+- 500 pp，最高 +- 3000 pp）至少 50 名玩家的 PPM 数据，并按正态分布计算玩家的相对水平。

在标准正态分布中，μ 是正态分布的数学期望（平均值），δ 是正态分布的标准差（方差的开方）。

PPM 4 根据离散数据，来近似推算这部分玩家的正态分布，并将玩家的 PPM 代入进去。即可得到玩家在正态分布密度函数上的位置，从而赋予一个 0-100 之间的分数，并赋予评价。

| 评价 | 赋分 | 参数所处的范围 | 超过玩家 |
| :-: | :-: | :-: | :-: |
| EX | 100.8-101 | x >= μ + 2δ 或者 x = max(x1, x2...) | 97-100% |
| SS | 100 - 100.8 | μ + 1.5δ <= x < μ + 2δ 或者 x < max(x1, x2...) | 93-97% |
| S | 90 - 100 | μ + δ <= x < μ + 1.5δ | 84-93% |
| A | 80 - 90 | μ <= x < μ + δ | 50-84% |
| B | 70 - 80 | μ - δ <= x < μ | 16-50% |
| C | 60 - 70 | μ - 2δ <= x < μ - δ | 2-16% |
| D | 0 - 60 | 0 <= x < μ - 2δ | 2% |

- EX：您该项数据已经是同分段的顶级水平。
- SS：您该项数据至少超过了 93% 的玩家，已经是百里挑一的级别。
- S：您该项数据至少超过了 84% 的玩家，说明您非常注意培养自己的能力。
- A：您该项数据至少超过了 50% 的玩家，位于平均水平之上。
- B：您该项数据至少超过了 16% 的玩家，注意练习弱势项目！
- C：您该项数据至少超过了 2% 的玩家，已经位于很低的水平。
- D：您该项数据已经是同分段的最低水平。

注意，如果分段人数太少（少于 5 人），则只会赋予默认的 80 分。并不代表玩家实际的水平。

::: details 内容解析

| 指标 | 名称 | 解析 |
| :-: | :-: | --- |
| **ACC** | 准度 | 相比之下更严格的 ::bullseye:: 准确率评价。越高，说明玩家的抓判定能力相较于同水平的玩家更高。 |
| **PTT** | 潜力 | 与玩家的最好成绩 ::arrow-up-right-dots:: 密度有关。越高，说明玩家的最好成绩榜更能塞下更多成绩，从而提升表现分。 |
| **STA** | 耐力 | 与玩家的每成绩均时长 ::clock:: 以及最好成绩均时长 ::clock:: 相关。越高，说明玩家相较于同水平的玩家，更喜欢打长图。 |
| **STB** | 稳定 | 与玩家的全连成绩占比以及最好成绩 ::ranking-star:: 评级有关。越高，说明玩家全连图的能力相较于同水平的玩家更高。 |
| **PRE** | 彩率 | 仅 osu!mania 存在。<br />与玩家最好成绩的 ::barcode:: 彩率有关。越高，说明玩家抓彩判定能力相较于同水平的玩家更高。 |
| **EFT** | 肝力 | 与玩家的 ::person-running:: 游玩次数和总击打次数有关。越高，说明玩家相较于同水平的玩家，投入了更多时间。 |
| **STH** | 强度 | 与玩家的 ::arrow-up-right-dots:: 每秒平均击打次数，以及前 10 个最好成绩与时长乘积相关。越高，说明玩家越能应付超出本分段水平的谱面。反之则更喜欢玩短图和简单的图。 |
|  |  |  |
| **OVA** | 综合 | 前 6 个值的加权和。一般来说，**80** 分即意味着玩家达到了分段平均水平。 |
| **SAN** | 理智 | 一般为 **100**。如果低于 100，则可能代表玩家的账号不正常，或玩家有其他类似游戏的经验。 |

:::
