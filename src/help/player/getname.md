可以通过输入玩家号来获取玩家名。

参见：[玩家/获取玩家号码](./getid.md)

::::: info 使用方法

!getname / gn / 玩家名称 [ ::slash:: 玩家号+]

:::: tabs

@tab ::slash:: 玩家号+

必选。

可以按分隔符号分隔，输入多个玩家号。参见：[技巧/多值参数](../../tips/trick/multiple.md)

::::

:::::

::: warning 注意

为防止滥用，只有群聊的群主或管理员可以使用此功能。

:::
