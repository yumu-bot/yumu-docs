可以查询过审状态的所有谱面。等效于[谱面列表（过审谱面）| osu!](https://osu.ppy.sh/beatmapsets?s=qualified)。


::::: info 使用方法

!qualified / q / 查询过审谱面 (`:` ::gamepad:: 游戏模式) (`#` ::file-circle-question:: 谱面状态) (`*` ::arrow-down-a-z:: 排序) ( ::hashtag:: 数量)

:::: tabs

@tab ::gamepad:: 游戏模式

可选。参见：[字段/游戏模式](../../tips/field/mode.md)

@tab ::file-circle-question:: 谱面状态

可选。参见：[字段/谱面状态](../../tips/field/status.md)

@tab:active ::arrow-down-a-z:: 排序

可选。可以输入的参数：

| 全称 | 简称 | 别称 |
| :-: | :-: | :-: |
| title | t | |
| artist | a | |
| difficulty | d、s | star |
| maprating | m | |
| plays | p | |
| ranked | r、t | time |

@tab ::hashtag:: 数量

可选。限制结果的数量。

- 如果小于等于 12，则会使用展开模式。
- 反之，则会使用密铺模式。
